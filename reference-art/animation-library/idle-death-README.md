# Mahery Animated Idle and Death Library v1

This pack contains animated exports for all 64 idle/death strips:

- 64 lossless animated WebP files
- 64 animated GIF previews
- 384 transparent PNG frames
- `animation-manifest.json` with facing direction, loop behavior, and frame timings

Idle animations loop continuously. Death animations play once and hold longer on the final grounded frame. Heroes and companions face right; enemies face left.
