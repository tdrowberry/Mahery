# Mahery Idle and Death Spritesheets v1

This pack contains 64 transparent six-frame horizontal sprite strips:

- 11 hero hybrids: idle and death
- 11 companion animals: idle and death
- 5 humanoid enemies: idle and death
- 5 enemy animals: idle and death

Heroes and companions face right. Enemies face left. Frames run chronologically from left to right. Every death is a non-graphic game defeat ending in a stable grounded pose.

Each PNG is divided into six equal-width cells. The companion and enemy-animal motions use species-appropriate movement rather than humanoid motion.
